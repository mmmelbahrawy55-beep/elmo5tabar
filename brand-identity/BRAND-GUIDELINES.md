# 2. LOGO SYSTEM

## 2.1 Primary Logo Concept

The Al Mokhtabar logo is built on three symbolic pillars:

### The Mark: "الحبر العلمي" (The Scientific Ink)

**Concept:** A stylized laboratory flask (Erlenmeyer) that transforms into a human figure with arms raised — symbolizing the fusion of science and humanity. The flask's body forms a stable triangular base (trust/stability), while the neck extends upward into a human silhouette (care/life).

**Geometric Construction:**
- Base: Equilateral triangle with 60° angles (stability, precision)
- Neck: Extends from triangle apex at 15° taper
- Human element: Two subtle arcs emerge from the neck, suggesting raised arms (vitality)
- Interior: A single droplet shape at the center (the "answer" — the result)

**The droplet** represents the moment of discovery — the single data point that transforms understanding of one's health.

### 2.3 Logo Lockup Specifications

**Primary Lockup (Vertical)**
```
         [MARK]
         
    المختبر
  AL MOKHTABAR
  
  LABORATORY
```
- Mark height: 3× the x-height of Arabic text
- Spacing between mark and Arabic name: 1.5× cap height
- Arabic to English spacing: 0.75× cap height
- Arabic text weight: Bold (700)
- English text weight: Medium (500), letter-spacing: +0.2em

**Horizontal Lockup**
```
[MARK]  المختبر | AL MOKHTABAR LABORATORY
```
- Mark height equals total text height
- Vertical separator: 1px line, height = 80% of text, color: 40% opacity
- Left padding from mark: 2× mark width

|-----------|---------------|-----------------|

| Horizontal | 35mm width | 120px width |

### 2.5 Clear Space

Minimum clear space around the logo = **the height of the letter "م" in المختبر**. No other elements, text, or graphics may enter this zone.

### 2.6 Incorrect Usage

**Never:**
- Rotate or skew the logo
- Change the logo colors to non-brand colors
- Add drop shadows or effects
- Place on busy/photographic backgrounds without overlay
- Stretch or distort proportions
- Recreate or modify the logo mark
- Use below minimum size
- Add outlines or strokes
- Animate the core mark (except approved loading animation)

# 4. TYPOGRAPHY

## 4.1 Font Selection

### Arabic: IBM Plex Sans Arabic
- **Rationale:** Designed for Arabic with Latin harmony. Clean, modern, scientific. Open-source, enterprise-grade.
- **Characteristics:** Geometric, generous x-height, clear diacritics, excellent legibility at all sizes.

### English: Plus Jakarta Sans
- **Rationale:** Contemporary geometric sans-serif. Pairs perfectly with IBM Plex Sans Arabic. Premium feel without pretension.
- **Characteristics:** Rounded terminals, friendly yet professional, excellent for data display.

### Monospace: JetBrains Mono
- **Rationale:** For lab codes, data, and technical information. Distinct l/1/I differentiation.
- **Characteristics:** Ligature support, clear character distinction, scientific aesthetic.

## 4.2 Type Scale

Based on a **1.250 (Major Third)** modular scale.

| Name | Size (px) | Size (rem) | Line Height | Weight | Usage |
|------|-----------|------------|-------------|--------|-------|
| `display-lg` | 60 | 3.75 | 1.1 | 800 | Hero headlines |
| `display` | 48 | 3.0 | 1.15 | 800 | Section headlines |
| `h1` | 36 | 2.25 | 1.2 | 700 | Page titles |
| `h2` | 30 | 1.875 | 1.25 | 700 | Card titles |
| `h3` | 24 | 1.5 | 1.3 | 600 | Subsections |
| `h4` | 20 | 1.25 | 1.35 | 600 | Component titles |
| `h5` | 16 | 1.0 | 1.4 | 600 | Small headings |
| `body-lg` | 18 | 1.125 | 1.65 | 400 | Large body text |
| `body` | 16 | 1.0 | 1.65 | 400 | Default body text |
| `body-sm` | 14 | 0.875 | 1.6 | 400 | Secondary text |
| `caption` | 12 | 0.75 | 1.5 | 400 | Captions, labels |
| `overline` | 11 | 0.6875 | 1.4 | 600 | Category labels, uppercase |

## 4.3 Font Weights

| Weight | Name | IBM Plex Sans Arabic | Plus Jakarta Sans |
|--------|------|---------------------|-------------------|
| 300 | Light | Available | Available |
| 400 | Regular | Body text | Body text |
| 500 | Medium | Labels | Labels |
| 600 | SemiBold | Subheadings | Subheadings |
| 700 | Bold | Headings | Headings |
| 800 | ExtraBold | Display | Display |

## 4.4 Arabic Typography Rules

1. **Line height:** Arabic requires 20% more than English. Use 1.6-1.8× for body text.
2. **Letter spacing:** Never apply positive letter-spacing to Arabic. It breaks ligatures.
3. **Word spacing:** Use `word-spacing: 0` for Arabic. Standard is too wide.
4. **Paragraph alignment:** Right-aligned for Arabic. Justified acceptable for long-form.
5. **Numbers:** Use Arabic-Indic numerals (٠١٢٣٤٥٦٧٨٩) for patient-facing content.
6. **Diacritics:** Ensure proper rendering of tashkeel when present.

## 4.5 Bilingual Typography Rules

When Arabic and English appear together:

1. **Arabic takes visual priority** — Always reads first (RTL context)
2. **Size ratio:** English text = 90% of Arabic text size
3. **Weight parity:** Match visual weight, not numeric weight
4. **Separator:** Use `|` (pipe) with 0.5em padding, color: `surface-300`
5. **Alignment:** Both languages align to the same baseline

Example:
```css
.brand-title {
  font-family: 'IBM Plex Sans Arabic', sans-serif;
  font-size: 2rem;
  font-weight: 700;
  color: #0F172A;
}

.brand-title-en {
  font-family: 'Plus Jakarta Sans', sans-serif;
  font-size: 1.8rem; /* 90% of Arabic */
  font-weight: 600;
  color: #64748B;
  letter-spacing: 0.05em;
}
```

## 4.6 Font Loading Strategy

```css
/* Preload critical fonts */
@font-face {
  font-family: 'IBM Plex Sans Arabic';
  font-style: normal;
  font-weight: 400 700;
  font-display: swap;
  src: url('/fonts/IBMPlexSansArabic-Regular.woff2') format('woff2');
}

@font-face {
  font-family: 'Plus Jakarta Sans';
  font-style: normal;
  font-weight: 400 800;
  font-display: swap;
  src: url('/fonts/PlusJakartaSans-Regular.woff2') format('woff2');
}
```

# 5. ICONOGRAPHY

## 5.1 Icon Style

- **Style:** Outlined (2px stroke) with rounded caps and joins
- **Grid:** 24×24px base grid
- **Padding:** 2px optical padding
- **Stroke:** 1.5px default, 2px for emphasis
- **Corner radius:** 2px
- **Color:** Single color, inherit from parent

## 5.2 Icon Categories

| Category | Style | Examples |
|----------|-------|---------|
| **Navigation** | Filled when active, outlined when inactive | Home, Lab, Orders, Reports |
| **Medical** | Detailed, scientifically accurate | Flask, Syringe, DNA, Heart |
| **Status** | Color-coded, filled | Check, Warning, Error, Info |
| **Actions** | Outlined with hover fill | Add, Edit, Delete, Download |
| **Social** | Brand-colored | Phone, Email, WhatsApp |

## 5.3 Custom Icon Set

A custom icon set of 120+ icons should be designed covering:

- **Laboratory:** Flask types, test tubes, microscope, centrifuge, slides
- **Medical:** Stethoscope, blood drop, bone, brain, lungs, DNA helix
- **Data:** Chart types, trending, analytics, report, barcode, QR
- **UI:** Standard navigation, actions, filters, sorts
- **Social:** Communication, sharing, notification

## 5.4 Icon Do's and Don'ts

**Do:**
- Use consistent stroke width (1.5-2px)
- Maintain optical alignment
- Use semantic colors for status icons
- Scale proportionally
- Test at all required sizes (16, 20, 24, 32, 48px)

**Don't:**
- Mix filled and outlined styles in the same context
- Use icons without text labels in navigation
- Apply multiple colors to a single icon
- Rotate icons (except refresh/loading)
- Use decorative icons in clinical/reports context

# 6. PHOTOGRAPHY DIRECTION

## 6.1 Photography Style

### Core Aesthetic
**"Clinical Warmth"** — Medical precision meets human warmth. Clean, well-lit, authentic moments in laboratory and healthcare settings.

### Lighting
- **Key:** Soft, diffused natural light (window light simulation)
- **Fill:** Minimal, maintaining natural shadows
- **Color temperature:** 5500K-6500K (daylight balanced)
- **Post-processing:** Clean, slightly desaturated, no heavy filters

### Composition Rules
- **Rule of thirds** — Subject at intersection points
- **Negative space** — Minimum 30% for text overlay capability
- **Leading lines** — Lab equipment, corridors, hands at work
- **Depth of field** — f/2.8-f/4 for portraits, f/8-f/11 for environments

## 6.2 Subject Categories

### People
- **Diversity:** Saudi/Gulf Arabic features, various ages, both genders
- **Expressions:** Focused, calm, confident — never stressed or anxious
- **Attire:** Brand uniforms, white coats, scrubs
- **Interactions:** Doctor-patient, technician-at-work, family-waiting
- **Hands:** Clean, gloved when clinical, demonstrating care

### Laboratory
- **Equipment:** Modern, clean, state-of-the-art
- **Process:** Hands working, samples being processed, machines running
- **Detail:** Macro shots of precision work, pipettes, samples
- **Environment:** Spotless, well-organized, advanced technology

### Environment
- **Interiors:** Bright, clean, modern architecture
- **Signage:** Brand elements naturally placed
- **Waiting areas:** Comfortable, premium, calming
- **Exterior:** Modern building, professional landscaping

## 6.3 Color Treatment

| Context | Treatment |
|---------|-----------|
| Brand imagery | Slight blue/teal color grade |
| Report backgrounds | Pure white, no color cast |
| Marketing | Warm-neutral grade, maintaining skin tones |
| Social media | Brand color overlay (20% opacity) for consistency |

## 6.4 Photography Don'ts

- No stock photos with visible watermarks
- No overly clinical/cold hospital imagery
- No distressed or anxious patients
- No cluttered backgrounds
- No harsh flash photography
- No heavy filters or Instagram-style processing
- No AI-generated people (use real photography)

## 19.3 App Icon Do's and Don'ts

**Do:**
- Keep it simple and recognizable at any size
- Use only the logo mark
- Maintain adequate padding
- Test at 32×32px for clarity
- Ensure it stands out on any home screen

**Don't:**
- Add text to the icon
- Use gradients (for primary icon)
- Add drop shadows
- Use photographs
- Make it too detailed (won't scale)
- Rotate the icon
- Use multiple colors (keep to brand blue + white)

# 20. BRAND GUIDELINE RULES

## 20.1 Brand Architecture

```
المختبر (Master Brand)
├── المختبر للمختبرات (Laboratory Services)
├── المختبر + (Premium/Concierge)
├── مختبري (My Lab — Patient App)
└── رؤية المختبر AI (AI Insights Platform)
```

### Sub-Brand Treatment
- **Master brand** always present
- Sub-brand name in lighter weight
- Connected by `+` or descriptive text
- Never standalone without parent brand

## 20.2 Co-Branding Rules

### With Partners
- Al Mokhtabar logo always on left (RTL: right)
- Minimum 50% size ratio vs partner logo
- Shared clear space
- Never modify either logo

### With Insurance Companies
- Partner logo in approved location only
- "شريك تأمين معتمد" (Certified Insurance Partner) label
- Specific logo placement per partner agreement

## 20.3 Digital Brand Rules

### Website
- **Header:** Logo horizontal, sticky navigation
- **Footer:** Full lockup + social icons + legal
- **Loading state:** Brand animation (logo draw)
- **Error pages:** Brand illustration + helpful message
- **Favicon:** Compact logo mark

### Email Signatures

- **Title slide:** Brand gradient background, logo, title
- **Content slides:** White background, brand header bar
- **Data slides:** Charts in brand colors
- **Closing slide:** Logo + contact information

## 20.4 Motion Design Principles

### Timing
- **Micro-interactions:** 150-200ms
- **Page transitions:** 300-400ms
- **Complex animations:** 500-800ms
- **Never exceed:** 1000ms

### Easing
- **Enter:** cubic-bezier(0.16, 1, 0.3, 1) — decelerate
- **Exit:** cubic-bezier(0.7, 0, 0.84, 0) — accelerate
- **Move:** cubic-bezier(0.45, 0, 0.55, 1) — standard

### Brand-Specific Animations
1. **Logo Draw:** Lines tracing the flask, then human figure
2. **Data Flow:** Dots flowing in curves (representing data/samples)
3. **Pulse:** Gentle breathing effect on logo (loading states)
4. **Reveal:** Content sliding in from right (RTL) with fade

## 20.5 Accessibility Requirements

### WCAG 2.1 AA Compliance
- **Color contrast:** 4.5:1 minimum for text
- **Focus indicators:** 2px `brand-500` outline
- **Alt text:** Required for all brand images
- **Screen reader:** Logo reads as "Al Mokhtabar Laboratory"
- **Motion:** Respect `prefers-reduced-motion`

### Color Blindness
- Never use color as the only indicator
- Always pair with icons, patterns, or text
- Test with: Deuteranopia, Protanopia, Tritanopia

## 20.6 Legal & Trademark

### Trademark Usage
- ® symbol after "المختبر | Al Mokhtabar Laboratory" in formal documents
- ™ symbol for sub-brands
- Never modify the trademarked logo

### Photography Rights
- All photography requires signed model releases
- Stock photos require commercial license documentation
- Patient photos require explicit consent forms
